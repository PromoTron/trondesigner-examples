Design Instructions

Pass the special custom property EDITOR:DESIGN_INSTRUCTION to show your customer instructions while they design. The editor displays the value as an informational notification labeled Design instructions: at the bottom of the design canvas, before any other informational messages. The instructions apply to the whole print job (all printings).

  • The key is case-sensitive — use it exactly as shown.
  • The notification appears only when the value is a non-empty string.
  • The value is saved with the print job like any other custom property. In Edit mode, pass the key again to update it, or an empty string to hide the notification. Omitting the key keeps the saved value.

Edge cases

Long text
Several sentences — check wrapping and that the canvas stays usable.
Markup in value
HTML / script in the value must never execute. Check how tags and quotes are displayed.
Empty string
Expected: no design instructions notification.
Whitespace only
Value "   ". Docs say only non-empty strings show a notification — check whether an empty notification appears.
Wrong key casing
Key editor:design_instruction. Expected: no notification (key is case-sensitive), stored as a normal custom property.

Implementation Code

1 — HTML data attribute

<button
    data-td-action="OpenCreate"
    data-td-supplier-code="PFC"
    data-td-product-code="10086021"
    data-td-print-position-code="front"
    data-td-print-technology-code="PAD03"
    data-td-custom-properties='{"EDITOR:DESIGN_INSTRUCTION":"Place your logo in the center of the print area."}'>
    Design your print
</button>

2 — JS builder

window.tronDesigner
    .addCustomProperty('EDITOR:DESIGN_INSTRUCTION', 'Place your logo in the center of the print area.')
    .setExactProduct('PFC', undefined, (p) => p.addVariant('10086021'))
    .addExactPrinting('front', 'PAD03')
    .open({ mode: 'dialog' });

3 — JSON editor arguments

window.tronDesigner.openDesigner({
    openMode: 'Create',
    dataMode: 'Exact',
    printJob: {
        customProperties: {
            'EDITOR:DESIGN_INSTRUCTION': 'Place your logo in the center of the print area.'
        },
        addProducts: { supplierCode: 'PFC', variants: [{ productCode: '10086021' }] },
        addPrintings: [{ printPositionCode: 'front', printTechnologyCode: 'PAD03' }]
    }
}, { mode: 'dialog' });

4 — Update or hide in Edit mode

// Custom properties are merged in Edit mode:
// pass a new value to update, '' to hide, or omit the key to keep the saved value.
window.tronDesigner.openDesigner({
    openMode: 'Edit',
    printJob: {
        printJobGuid: printJobGuid,
        customProperties: { 'EDITOR:DESIGN_INSTRUCTION': '' }
    }
}, { mode: 'dialog' });

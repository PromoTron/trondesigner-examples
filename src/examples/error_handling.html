Error Handling

The integration script reports most problems in the browser console instead of throwing. Where your code can react:

  • Initialization - check getInitialized() before opening, or await getInitializing() (rejects on failure); see the Init Failure example.
  • Opening the editor - openDesigner() and open() return nothing (no promise; chaining .then() throws a TypeError). Unknown codes, a missing print job and similar problems show the editor's error dialog; closing it calls onClose('Error').
  • Invalid custom buttons - setEditorButtons() / addEditorButton() throw synchronously.
  • API methods (getPrintJob, getProofreading, clonePrintJob, ...) - the promise rejects.

Close the editor's error dialog to see the onClose result in the log below. Add data-td-log-level="debug" to the script tag for detailed console output while you develop.

Invalid Product Code

Editor shows No products found; closing it logs onClose('Error').

Invalid Print Configuration

Editor shows Selected print options not found; closing it logs onClose('Error').

Invalid Print Job GUID

Editor shows Print job ... not found; closing it logs onClose('Error').

Invalid Custom Button

setEditorButtons() throws synchronously - caught with try/catch, the editor doesn't open.

Rejected API Call

getPrintJob() with an unknown GUID - the promise rejects, caught with try/catch.

Error Handling Patterns

1. Wait for initialization

try {
    await window.tronDesigner.getInitializing();   // rejects when initialization failed
} catch (error) {
    console.error('Designer not available:', error.cause ?? error.message);
}

// or, right before opening:
if (!window.tronDesigner?.getInitialized()) {
    showError('The designer is not available right now.');
}

2. React to editor errors with onClose

// openDesigner() returns nothing - don't chain .then() / .catch()
window.tronDesigner.openDesigner(editorArguments, {
    mode: 'dialog',
    onClose: (reason) => {
        // 'Confirmed' | 'Cancelled' | 'Error'
        if (reason === 'Error') showError('The designer could not be loaded. Please contact us.');
    }
});

3. Synchronous validation errors

try {
    window.tronDesigner
        .setEditorButtons(buttonsFromConfig)   // throws on invalid buttons - call it first
        .setExactProduct('PFC', undefined, (b) => b.addVariant('10086021'))
        .addExactPrinting('front', 'PAD03')
        .open({ mode: 'dialog', onClose });
} catch (error) {
    console.error('Could not open the designer', error);
}

4. API calls

try {
    const printJob = await window.tronDesigner.getPrintJob(printJobGuid);
} catch (error) {
    console.error('Print job could not be loaded', error.message, error.cause);
}

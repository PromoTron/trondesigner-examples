Logo Visualization

Instead of a JS button opening the editor, plain <img data-td-action="RenderVisualization"> elements are scanned automatically on page load. Each one declares a supplier + exact product variant + print position/technology; the script batches these into render token requests and swaps src for the rendered visualization of the customer's currently selected logo.

Product used: Teak A5 recycled hard cover notebook (106013_TD).

  • No logo selected → images show their original src (the plain product photo).
  • Upload or select a logo below → every matching image re-renders automatically.
  • Clear the logo → images reset to their original src.
  • Each variant/position/technology combination requires its own <img> - one image can only ever represent one exact print option on one exact variant.

Implementation Code

<!-- Scanned automatically once the SDK initializes - no click handler needed -->
<img
    data-td-action="RenderVisualization"
    data-td-supplier-guid="88be5fc8-0eed-4dbe-b25b-5e8d4e49696b"
    data-td-product-code="10601355_TD"
    data-td-print-position-code="FRONT"
    data-td-print-technology-code="DPRINT03"
    src="product-default.jpg"
    alt="Teak A5 notebook - Navy"
/>

<!-- Optional attributes -->
<!-- data-td-visualization-size="max600"                          fixed output size instead of the img's own pixel size -->
<!-- data-td-visualization-logo="f47ac10b-58cc-4372-a567-..."      per-image logo override, ignores the customer's selected logo -->

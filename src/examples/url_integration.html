URL Integration (No JavaScript)

URL Integration opens TronDesigner on the Integration Site ({TD_URL_INTEGRATION}/editor) from a link - no script on your page.

Use cases: Email links, QR codes, server-side redirects, simple integrations

Three link formats: simple parameters (below), the full editor arguments as URL-encoded JSON in options, or a signed token link generated by your server through the REST API (the configuration can't be read or changed in the URL).

The link runs outside your site, so you don't receive browser events - use webhooks and the REST API to get the result. The API key must allow the Integration Site's host name.

Create Mode - Exact Product

Open via URL
Direct link to editor
URL:
{TD_URL_INTEGRATION}/editor?apiKey={TD_API_KEY}&supplierCode=PFC&productCodes=10086021&positionCodes=front&technologyCodes=PAD03

Partial Mode - Model Only

Open via URL
User selects variants
URL:
{TD_URL_INTEGRATION}/editor?apiKey={TD_API_KEY}&supplierCode=PFC&modelCode=100860

Edit Mode - Existing Print Job

URL Format:
{TD_URL_INTEGRATION}/editor?apiKey={TD_API_KEY}&printJobGuid=[GUID]&openMode=Edit

View Mode - Read Only

URL Format:
{TD_URL_INTEGRATION}/editor?apiKey={TD_API_KEY}&printJobGuid=[GUID] (openMode defaults to View)

Simple URL Parameters

Parameter Description
apiKey Website integration API key (required)
supplierCode Supplier code, e.g. PFC
productCodes Product variant code; repeat for several variants
modelCode Product model code - the customer chooses the variants (Partial data mode)
positionCodes Print position code (e.g. front); repeat for several print options
technologyCodes Print technology code (e.g. PAD03), paired with positionCodes by order
printJobGuid Existing print job GUID
openMode Edit or View (default) - used with printJobGuid
showSelectedVariants, showSelectedPrintOptions None (default), Selected, All or Missing
showQuantityInputs, alwaysShowImageSelect true to turn the option on
customerIdentity Your ID of the customer
options Complete editor arguments as URL-encoded JSON (takes precedence over the other parameters)

Parameter names are case-sensitive. There is no dataMode parameter - the data mode follows from the parameters you use. A return URL is only available for token links.

Implementation Code

Building a link with full JSON options

const args = {
    openMode: 'Create',
    dataMode: 'Exact',
    printJob: {
        addProducts: { supplierCode: 'PFC', variants: [{ productCode: '10086021' }] },
        addPrintings: [{ printPositionCode: 'front', printTechnologyCode: 'PAD03' }],
        customer: { orderCode: 'SO-2026-0042' },
        customProperties: { cartItemId: '4711' }
    }
};

const url = new URL('{TD_URL_INTEGRATION}/editor');
url.searchParams.set('apiKey', '{API_KEY}');
url.searchParams.set('options', JSON.stringify(args)); // URLSearchParams encodes the JSON

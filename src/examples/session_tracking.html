Session Tracking & Identifiers

Link print jobs to your application's users, orders, and cart items for seamless e-commerce integration.

Available Tracking Fields (in printJob):

  • customer.customerIdentity - Your user identifier (link designs to user accounts); also customerPerson, customerCompany, customerEmail
  • customer.orderCode / customer.orderTitle - Your order identifier and title (connect to specific orders)
  • customer.orderItemCode - Shopping cart line item tracking
  • customProperties - Your own key/value metadata (string values) for analytics or business logic

Use Cases

E-Commerce Integration

  • Link print jobs to cart items
  • Enable "edit from cart" workflow
  • Track designs through checkout
  • Associate with order after purchase

User Management

  • Display user's past designs
  • Enable design library per user
  • Track user design activity
  • Personalization based on history

Analytics & Reporting

  • Campaign performance tracking
  • A/B test variant tracking
  • Conversion funnel analysis
  • Custom business metrics

Implementation Code

td.openDesigner({
    "openMode": "Create",
    "dataMode": "Exact",
    "printJob": {
        "addPrintings": [
            {
                "printPositionCode": "front",
                "printTechnologyCode": "PAD03"
            }
        ],
        "addProducts": {
            "supplierCode": "PFC",
            "variants": [
                {
                    "productCode": "10086021"
                }
            ]
        },
        "customer": {
            "customerIdentity": currentUserId,
            "customerEmail": currentUserId + "@example.com",
            "customerPerson": "User " + currentUserId,
            "customerCompany": "Company of " + currentUserId,
            "orderCode": currentOrderId,
            "orderItemCode": currentCartItemId,
            "orderTitle": "Example Product in Cart"
        },
        "customProperties": {
            campaignId: "summer2024",
            source: "product_page",
            sessionStart: "2024-06-01T12:00:00Z",
            userSegment: "premium"
        }
    },
}, {mode: "dialog"});

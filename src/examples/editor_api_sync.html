Editor API – Product configurator

A product page with a configurator next to the inline editor. The configurator is the source of truth: after every change it sends the whole selection with editor.syncPrintJob(), and the editor adds, removes and replaces colours and printings to match - in one step, all or nothing.

Try: add a logo in the editor, then change the technique of the front to Screen transfer (the design is carried over unchanged) or to Transfer reflective (one colour: the logo is prepared again and the editor may ask you to confirm). Add the back or the small front zone, untick a zone that has a design (you are asked first), add a colour, or click a printing tab in the editor (the configurator follows).

Implementation Notes

  • Every selected colour is a variant of the print job, every selected zone a printing (print position + technique). Send the whole selection after each change - the editor works out what to add, remove and replace.
  • A new technique for a zone replaces the zone's printing and carries the design over: same size and place in millimetres, scaled down or moved if it does not fit, the logo prepared again for another colour mode. result.replaced[].graphics and adaptations tell you what happened.
  • removeWithGraphics: 'reject' fails with INVALID_STATE instead of removing a zone with a logo or text - ask the customer, then sync again without it.
  • If a sync fails (NOT_FOUND, ABORTED, …) nothing changed: put the configurator back.
  • Run the changes one after another - a second change while the first is running fails with BUSY.
  • The first time a colour or zone is added, the editor loads its product data and mockup, so it takes a moment.

Code Example:

const result = await editor.syncPrintJob({
    variants: [{ productCode: "MO8360-03", quantity: 50 }, { productCode: "MO8360-04", quantity: 100 }],
    printings: [{ printPositionCode: "FRONT", printTechnologyCode: "T1" }],
    show: { variantCode: "MO8360-04", printPositionCode: "FRONT", printTechnologyCode: "T1" }
}, { removeWithGraphics: "reject" });

for (const { to, graphics, adaptations } of result.replaced) {
    if (graphics === "adapted") showMessage(`${to.printPositionCode}: ${adaptations.join(", ")}`);
}

editor.addEventListener("tdSelectionChange", ({ detail }) => {
    if (detail.source === "user") highlightZone(detail.printPositionCode);
});

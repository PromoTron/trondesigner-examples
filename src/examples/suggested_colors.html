Suggested Design Colors

Pass your customer's brand colors as custom properties EDITOR:DESIGN_COLOR_<number> (e.g. EDITOR:DESIGN_COLOR_1, EDITOR:DESIGN_COLOR_10). Keys are case-sensitive, the suffix must be a non-negative integer, colors are shown in numeric order and gaps are allowed. Each value has the format Source:ColorValue:

  • PMS:PANTONE 185 C — full Pantone name from the color map
  • RGB:#EB002A or RGB:#EB002AFF — 6 (RGB) or 8 (RGBA) hex digits
  • CMYK:#00F8D000 — four channel bytes #CCMMYYKK (00 = 0 %, FF = 100 %)

The value must match the color map exactly (case and surrounding whitespace are ignored); the nearest color is not chosen.

What it does:

  • Suggested Colors section at the top of the logo and text color selectors (Pantone and CMYK). Unmatched or invalid entries stay visible but disabled, with an error icon.
  • Automatic logo recoloring — when exactly one non-empty color is supplied and it matches the map, logo adaptation recolors the whole logo to it for Pantone, CMYK and SingleColor print modes. Colorless modes keep their normal behavior. Applies to the initial integration logo and later uploads/replacements, never to logos already placed in a saved design.

3. No automatic recoloring expected



    

        Two colors, same result
        
PMS:PANTONE 185 C + RGB:#EB002A both resolve to 185 C. Multiple supplied colors
            prevent recoloring. Both appear in Suggested Colors.

        
    


    

        One matched + one unmatched
        
Only one matches, but two are supplied → no recoloring.

        
    


    

        Single unmatched
        
RGB:#EB002B is valid syntax but not in the map (no nearest match) → normal adaptation,
            disabled suggestion with error icon.

        
    


    

        Invalid keys
        
editor:design_color_1 (wrong case), EDITOR:DESIGN_COLOR_A, EDITOR:DESIGN_COLOR_-1
            → ignored: no Suggested Colors section at all, no recoloring.

Implementation Code


    
1 — HTML data attribute

    
<button
    data-td-action="OpenCreate"
    data-td-supplier-code="PFC"
    data-td-product-code="10086021"
    data-td-print-position-code="front"
    data-td-print-technology-code="PAD03"
    data-td-custom-properties='{"EDITOR:DESIGN_COLOR_1":"PMS:PANTONE 185 C"}'>
    Design your print
</button>


    
2 — JS builder

    
window.tronDesigner
    .addCustomProperties({
        'EDITOR:DESIGN_COLOR_1': 'PMS:PANTONE 185 C',
        'EDITOR:DESIGN_COLOR_2': 'RGB:#0033A0'
    })
    .setExactProduct('PFC', undefined, (p) => p.addVariant('10086021'))
    .addExactPrinting('front', 'PAD03')
    .open({ mode: 'dialog' });


    
3 — JSON editor arguments (single color → automatic logo recoloring)

    
window.tronDesigner.openDesigner({
    openMode: 'Create',
    dataMode: 'Exact',
    printJob: {
        logo: { url: 'https://cdn-webassets.promotron.com/images/td/logo-full-light-theme.svg' },
        customProperties: {
            'EDITOR:DESIGN_COLOR_1': 'CMYK:#00F8D000'   // = PANTONE 185 C
        },
        addProducts: { supplierCode: 'PFC', variants: [{ productCode: '10086021' }] },
        addPrintings: [{ printPositionCode: 'front', printTechnologyCode: 'PAD03' }]
    }
}, { mode: 'dialog' });


    
Encoding a CMYK value

    
// CMYK:#CCMMYYKK — each channel is one byte (00 = 0 %, FF = 100 %); the last pair is black, not alpha.
const toByte = (percent) => Math.round(percent * 255 / 100).toString(16).padStart(2, '0').toUpperCase();
const cmyk = 'CMYK:#' + [0, 97, 82, 0].map(toByte).join('');   // 'CMYK:#00F7D100'
// Note: rounding percentages does not guarantee an exact color-map match (185 C is CMYK:#00F8D000).

View Mode (Read-Only)

View Mode opens the editor in read-only mode. Users can see the design but cannot make changes or save.

Use cases: Order confirmation display, design approval review, customer service viewing, proof verification

Features: No tools to add or change logos, texts or print options. The Continue button still shows the Final Verification summary, but nothing can be confirmed or saved and no print job event is fired.

View with Manual GUID

Implementation Code

// 1. Remember the GUID of the created print job (event.entityGuid)
window.tronDesigner.subscribeDesignerEvent('printJob', 'created', (event) => {
    printJobGuid = event.entityGuid;
});

// 2. Open it again in View mode
window.tronDesigner.openDesigner({
    openMode: 'View',
    printJob: { printJobGuid: printJobGuid }
}, { mode: 'dialog' });

// or with the builder
window.tronDesigner.setPrintJob(printJobGuid, 'View').open({ mode: 'dialog' });

Event Handling & Callbacks

TronDesigner provides comprehensive event callbacks to track editor lifecycle and print job changes.

Available Events (entityType / eventType):

  • printJob / created - A new print job was saved
  • printJob / updated - An existing print job was saved again
  • logo / created, updated, deleted - The customer uploaded, changed or deleted a logo
  • logo / selected - A logo was selected in the logo gallery or upload dialog
  • text / created - A text was created in the editor
  • proofreading / created - A proofreading PDF was generated

There are no editor open/close events: pass an onClose(reason) callback in the open options instead.

Implementation Code

// Subscribe to events
const td = window.tronDesigner;

td.subscribeDesignerEvent("printJob", "created", (event) => {
    console.log("Print job created:", event.entityGuid, event.detail);
});

td.subscribeDesignerEvent("printJob", "updated", (event) => {
    console.log("Print job updated:", event.entityGuid);
});

td.subscribeDesignerEvent("proofreading", "created", (event) => {
    console.log("Proofreading PDF generated:", event.detail); // Blob
});

// Editor closed: use the onClose callback of the open options
td.openDesigner(editorArguments, {
    mode: "dialog",
    onClose: (reason) => console.log("Editor closed:", reason) // 'Confirmed', 'Cancelled' or 'Error'
});
